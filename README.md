# 💫 About Me:
I am a Java Backend Developer with a strong focus on building clean, scalable, and maintainable backend applications using Spring Boot, Spring Data JPA, and PostgreSQL. I enjoy working on backend systems where good design, clean architecture, and correct data flow matter more than just making things work.<br><br>I have hands-on experience designing RESTful APIs following a layered architecture, and I actively apply DTO and Mapper patterns to maintain a clean separation between API contracts and persistence models. I believe entities should never be exposed directly to controllers, and I design my applications accordingly.<br><br>I have implemented pagination, sorting, and filtering using Spring Data JPA and understand why pagination should be handled at the repository level for performance and scalability. To keep APIs frontend-friendly, I work with custom response structures and PageResponseDTOs, ensuring that only meaningful data is exposed while hiding framework-specific internals.<br><br>I am comfortable working with JPA/Hibernate ORM, entity relationships (@ManyToOne, @OneToMany), and validation at the API boundary using @Valid. I also have experience implementing global exception handling using @ControllerAdvice to produce consistent and meaningful error responses across the application.<br><br>Currently, I am expanding my knowledge in microservices architecture, backend system design, and performance-aware API development. Alongside development, I actively practice Data Structures & Algorithms to strengthen my problem-solving skills and prepare for backend-focused interviews.<br><br>I enjoy learning by building real projects, refactoring code to improve design, and understanding the “why” behind architectural decisions. My long-term goal is to grow as a strong backend engineer capable of designing reliable systems and contributing to impactful products.
